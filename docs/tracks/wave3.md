# Wave 3 — calendar-aligned analytical research

The event threshold tracker remains separate from the return study. The replacement return engine emits one point per finalized input bar including inactive periods and ongoing horizons. It uses a fixed **one-unit price-change index normalized by the first study close**, with additive cumulative changes. This is a research index, without fills, reinvestment, an account balance or an executable-price claim.

A signal can affect only an interval after its recorded availability and observation timestamp. Earliest newly available event wins; simultaneous later arrivals and arrivals during an active horizon are discarded. Horizons count observed finalized intervals. The final unfinished horizon retains accrued observations; future suffix availability never changes earlier path points. Duplicate identical snapshots deduplicate, while conflicting snapshots reject. Missing exchange sessions are not imputed and data completeness is not claimed.

Half commission/spread/slippage/impact allowance is assigned to each analytical endpoint. Sale-side regulatory allowances use the actual New York date: beginning for a bearish event, end for bullish. Borrow accrues ACT/365 on the immutable signal reference price. All are normalized by the same initial study close. Unknown fee dates preserve gross observations and turn the costed index unavailable from that point. SPY defaults to an explicit $0.02 full spread, $0.01/$0.05 sensitivities, one basis point slippage per endpoint, zero impact/commission and 3% annual bearish borrow. For other symbols, $0.02 is labeled a **SPY proxy assumption**, not an inferred instrument spread.

The report preserves its existing shared schema. Metrics add interval count, coverage, discarded overlaps, completed/started event counts, analytical unit transitions and transitions/interval, profit factor, expectancy, CVaR, drawdown, underwater fraction/duration, SPY excess return and Sharpe difference, cost sensitivities, circular-shift null, bootstrap interval, regime cohort counts/means and optional publication cohort. Metric names and assumptions explain their denominators. The plotted series is the additive costed index; the SPY comparison is a gross fixed-reference index with exact same-feed timestamps and known availability. Any absent benchmark timestamp disables the benchmark instead of forward-filling it.

Annualized Sharpe/Sortino and the explicitly labeled arithmetic-reference-return Calmar variant require at least 252 daily intervals, unique weekday dates and plausible session gaps. Intraday annualization remains unavailable. Sharpe uses zero hurdle and sample variance; downside deviation includes all intervals with zero contributions above the hurdle. Nonpositive index levels disable percentage drawdown and annual ratios. Infinite ratios, short samples and empty cohorts stay null. Raw prices do not establish corporate-action-adjusted total returns.

Bootstrap uses 1,000 deterministic circular block resamples with approximately square-root-length blocks and at least 60 intervals. The circular-shift null retains serial exposure structure and fixed allowances; it is a descriptive alignment check, not an adjusted significance claim. Regime diagnostics require at least 315 daily intervals; prior 63-bar trend and prior 21-bar volatility relative to its preceding baseline label each interval without using that interval's return. Each descriptive regime mean requires 30 members. Publication comparison requires a supplied verified timestamp and 60 subsequent intervals.

Deflated Sharpe is implemented from [Bailey and López de Prado](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf) with unannualized comparable trial Sharpes, their cross-trial dispersion, nonnormal return moments and the expected maximum. The default API supplies no complete trial registry, so the value remains unavailable with a reason. An integration caller must explicitly pass `trial_sharpes` and `trial_registry_complete=True`; an incomplete list must never be relabeled complete. A count alone is insufficient. Overfitting probability remains unavailable without a full trial return matrix and independent holdout.

Validation: handmade paths including flat intervals and overlap; delayed timestamps; prefix/suffix equality for immature events; SEC schedule boundary across two horizon endpoints; shared total-cost parity; unknown fee coverage; additive drawdown and underwater arithmetic; annualization thresholds; bootstrap/null reproducibility; complete-registry checks; exact benchmark alignment. Existing API tests retain the expected unavailable short-history Sharpe. No statistical superiority is asserted.
