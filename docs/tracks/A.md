# Track A — Optional data adapters and durable ingestion

Service interfaces are implemented in `adapters.py` and `ingestion.py`; no automatic routing replaces the active Alpaca provider. `provider_catalog(config)` inspects configuration only. The integration agent may expose that metadata in authenticated settings. To ingest deliberately selected data: instantiate an adapter, await `fetch(dataset, **query)`, then call `ingest_batch(store, archive, batch, symbol, timeframe)`. Use `replay_bars` with explicit feed/source/as-of.

Implemented requests and parsers: Finnhub timestamped quotes/candles; Alpha Vantage compact raw daily bars; Twelve Data 5m/1h/daily bars; FRED date-vintage observations with missing values; SEC submissions/company facts; French daily three-factor ZIP CSV. Optional SDK adapters for yfinance raw daily history and Databento daily bars are implemented but require installation and explicit enablement. Massive bars require an explicit paid entitlement. Historical Alpaca SIP is separately selected, gated by verified entitlement, and ends at least 16 minutes before retrieval; it never substitutes for IEX.

No alternate provider is presented as an authenticated live integration. Data delay is unknown unless specified. Unverified venue coverage never asserts SIP/consolidated volume. API errors are sanitized, credential echoes rejected, redirects disabled, responses size-bounded, and request destinations fixed. Paid adapter catalog entries are unconfigured by default. Optional SDK imports are lazy.

DataBatch carries source/dataset/feed/version, retrieval timestamp, availability policy, limitations and raw checksum. Historical dissemination timestamps generally cannot be recovered from a candle response: normalization uses conservative retrieval-time availability. FRED vintage dates are retained but are not promoted to intraday release timestamps. French factors remain retrospective research inputs with percentage units. SDK archives explicitly identify their normalized payload rather than pretending to preserve raw HTTP.

Immutable content-addressed archival envelopes include payload checksums and metadata. Ingestion writes only finalized validated OHLCV bars to the existing durable table. Repeated batches are idempotent; source/version collisions and revised price values fail instead of overwriting history. Every conflicting response still has an archive. SIP and IEX remain separate database keys. As-of replay filters recorded availability and source. The existing table cannot hold simultaneous alternative providers on the same symbol/feed/timeframe/time key; this is enforced as a collision, and multi-provider comparison needs a future schema migration.

Verification: ten deterministic offline tests passed, covering fixed request parameters, quota/entitlement failure, credential echo/redirect rejection, FRED vintages, UTC parsing, SEC identity, French units, archive integrity, durable idempotence, feed separation and as-of replay. No live credentials were accessed or optional providers probed.
