# Track G — advanced context and alpha features

Independent research implementations cover families 8–13 with explicit missing-input results. No adapter invents missing data. `advanced_catalog(feed)` is disabled by default because a single-symbol bar request cannot establish a point-in-time universe. The integration surface is `evaluate_advanced(id, bars, timeframe, Context(...)) -> Evaluation`; its signals use frozen shared Signal models. Context/Observation/Evaluation are backend-local types, not new shared wire contracts. `apply_volatility_gate` tests every event against its own availability timestamp and blocks the study if required observations are absent.

- Pairs: prior 252 aligned adjusted daily sessions, current held-out residual, rolling Engle–Granger p<0.05 and two-standard-deviation excursion. Uses actual statsmodels cointegration critical values, rejects constants/degeneracy. Reference signal is one symbol, not a paired exposure or a virtual account. Integration supplies historical point-in-time two-member membership.
- Momentum: monthly observation, prior 253 aligned daily observations excluding current session, approximate 12–1 window from adjusted prices, upper/lower 30% rank. Membership must already be known. Adjusted inputs must represent the intended total-return history; no adjustment is manufactured.
- Factor tilts: equal-weight cross-sectional descriptor ranks for value, size, quality, momentum, low-volatility; explicitly a research variant, not a claim to replicate Fama–French factor returns. All members require dated observations within 180 days.
- Earnings: standardized surprise supplied by a source, known at observation, at least absolute 1, first finalized daily observation after publication, five-calendar-day freshness. Missing surprise cannot be replaced with headline sentiment.
- Volatility: fresh positive VIX spot/3-month values and 252 unique daily IV observations. Gate requires term ratio below 1 and IV range-rank below 0.8. Constant IV is unavailable. No independent directional signal.
- Seasonality: prior matured next-session returns grouped by weekday, turn-of-month and pre/post-FOMC, each with at least 30 samples for inference and a two-standard-error exploratory threshold. FOMC schedules must have been known at each historical decision timestamp; absent schedules stay explicitly unavailable. The exchange calendar must extend into the following month. No claim that weekday associations survive multiple-testing correction.

Alpha coverage is **all 87 nonbinary formulas out of the 101 published definitions**, with **14 pure binary formulas explicitly excluded**: 21, 27, 61, 62, 64, 65, 68, 74, 75, 79, 81, 86, 95, 99. All remaining IDs are implemented. 23 formulas contain no volume dependency, but 48 and 56 additionally require point-in-time industry/market-cap context. `alpha_catalog(feed)` contains 101 entries, including exclusion reasons and explicit required-input lists. `alpha_features(panel, feed, as_of, adjusted=True, observations=[AlphaObservation(...)])` returns numeric features by member. Version 2 corrects the earlier average-share-volume convention to the paper's average **daily dollar volume** definition; prior version-1 feature snapshots must not be mixed with version 2.

VWAP-dependent formulas require sourced actual daily VWAP; ADV-dependent formulas require sourced daily dollar volume. They are never estimated from close, high/low/close averages or IEX market share. Industry-dependent formulas require daily timestamped sector/industry/subindustry labels, and formula 56 requires market capitalization. These extra observations carry source, feed, observation and availability. A missing member invalidates that contextual row for the complete cross section; missing current inputs disable the formula with a structured reason. Late context cannot rewrite earlier feature history. No classifications or fundamentals are fabricated. Numeric context must be finite/nonnegative, and supplied VWAP/capitalization must be positive.

All formulas require an explicitly declared adjusted daily panel, at least two members, exact timestamp alignment, and known availability. Caller owns point-in-time universe selection and must retain provenance. Volume-dependent formulas fail closed without SIP even if synthetic volume is present. Each output preserves feed, observation/availability time, version and input requirements.

`information_coefficient_decay(snapshots, panel, as_of, horizons=(1,5,20))` measures mean cross-sectional Spearman rank association only for fully matured subsequent price labels. It requires at least three finite, nonconstant member ranks per cohort, rejects duplicate snapshots/mixed formula versions/feed mismatch, reports matured/missing counts, and never uses labels unavailable at the requested timestamp. It is descriptive: overlapping labels do not produce an independence-based significance claim.

Cross-sectional ranks run across symbols at each timestamp; time-series ranks run only across trailing windows, using average ties and one-based ranks. Fractional periods are floored as specified in the paper; linear decay weights increase from oldest to newest. Group neutralization subtracts the cross-sectional mean within the contemporaneously supplied group. Standard deviations use population normalization; covariance uses the pandas sample convention. Zero denominators and zero-variance correlations produce unavailable values. No fill-forward, price-derived VWAP, imputed sector classification or consolidated-liquidity estimate exists. Formula outputs with insufficient warm-up remain null. All signals retain source feed and known timestamps; alpha feature metadata carries feed, availability and version while provider lineage remains with the input dataset.
