# Source and license audit

Public Traders extension (2026-09-09): adapter and normalization code are original; no eToro SDK or provider source code was imported and no new dependency was installed. API documentation is used as a schema reference, not as a data-use license. Real eToro caching/display/OpenAI rights remain unverified; Kinfo scraping is excluded and AfterHour sharing requires approved access. Synthetic test records are authored locally. Qualification, source links and unsent permission inquiries are in [Public Traders](docs/PUBLIC-TRADERS.md). The scanner's new explicit exception is the authorized third-party public-user evidence namespace; private broker paths remain prohibited and runtime requests have a separate GET-only allowlist.

Audited September 9, 2026. This inventories all 29 repositories named in Part 5 plus the accepted pandas-ta-classic replacement. The 29 accessible repositories have immutable revision pins; the original pandas-ta URL returned 404 and is excluded. No upstream source files were imported by this audit.

The audit covers recursive license/notice file inventories and selected source headers, not every file in every upstream repository. This is sufficient for the present decision to avoid source copying. Any later copied/adapted file needs an explicit file-level review and attribution before integration. Package installation also requires auditing the exact resolved release and its transitive dependencies; reference HEAD pins below do not substitute for lockfiles.

## File-level findings and notices

- The machine-readable [evidence inventory](docs/license-evidence.json) records full commit IDs, all discovered license/notice paths, SHA-256 content hashes, selected source headers, and explicit unresolved items. PyPortfolioOpt was inventoried from its pinned archive after API rate limiting.
- Nautilus crate license files resolve back to its LGPL root. Its Python distribution is LGPL; the vendored pyo3-stub-gen patch has separate Apache and MIT files. None is imported.
- vectorbt has Apache terms with the Commons Clause, separate AGPL documentation, and explicit Commons Clause source headers. It is not treated as an unrestricted Apache dependency.
- StockSharp root LICENSE and NOTICE establish proprietary terms governed by the vendor EULA. Its code and architectural implementations are excluded. The original plan’s Apache label is incorrect.
- backtesting.py is AGPL; NostalgiaForInfinity and Freqtrade are GPL. Concepts are independently implemented, and those packages are absent from the runtime dependency policy.
- WorldQuant_alpha101_code has no discovered license and its sampled source headers supply no license grant. The systematic-trading index likewise has no discovered root license. Public visibility does not establish reuse permission.
- Stock-Prediction-Models includes Google copyright and Apache headers in deep-learning/access.py and addressing.py. A repository’s author is not necessarily the sole copyright holder.
- TA-Lib’s wrapper includes a separate COPYRIGHT file identifying Silfur Capital and Brian A Cappello for the abstract module. Preserve it alongside the BSD license if enabling this optional package.
- Lightweight Charts requires its package LICENSE and NOTICE plus user-visible TradingView attribution and link on both surfaces. Its README identifies bundled tslib under 0BSD. Plugin templates and toolkit have their own notices; they are not automatically imported with the chart renderer.
- pandas-ta-classic’s MIT license identifies both pandas-ta and pandas-ta-classic contributors. The inspected pyproject requires Python >=3.10, numpy >=2.0 and pandas >=2.0; target Python 3.12 is compatible with this declared requirement. Actual dependency resolution and indicator parity tests remain separate build evidence.
- mlfinlab is explicitly excluded. The root and documentation licenses contain different dated custom terms; no permissive entitlement is inferred. Only license metadata was inspected.

## Distribution requirements

Before publishing either client, retain the exact LICENSE/NOTICE texts from the installed Lightweight Charts release in distributed third-party notices and render its TradingView attribution/link. Retain MIT/BSD/Apache license and copyright texts for resolved backend dependencies in server distribution artifacts. Do not translate, abbreviate, or replace package notices with this summary.

MIT/Apache/BSD/CC0 entries above permit consideration of the stated research use subject to their terms; they do not approve datasets, trademarks, model weights, API redistribution, or every transitive component. GPL, LGPL, AGPL, Commons Clause, proprietary, missing-license and unavailable sources are excluded from code reuse in the accepted implementation.

## Remaining evidence boundaries

The original pandas-ta repository cannot be pinned because it is unavailable; replacement is the recorded resolution. No clearance is asserted for unreviewed source files, future upstream revisions, linked repositories, upstream datasets or model weights. Optional dependencies must be checked against their exact lockfile artifacts before enabling them. This audit makes no claim that client distribution, deployment, or real-device acceptance has been verified.
